# Vocabulary Building

Track and organize new English vocabulary, especially technical terms.

## Technical Vocabulary

### Programming Terms

- **Refactoring** - Restructuring existing code without changing its external behavior
- **Debugging** - The process of finding and fixing bugs in code
- **Deployment** - The process of making software available for use
- **Scalability** - The ability of a system to handle increased load

### Development Process

- **Code Review** - Systematic examination of source code
- **Version Control** - System for tracking changes to files
- **CI/CD** - Continuous Integration/Continuous Deployment
- **Documentation** - Written explanation of code functionality

## Daily Vocabulary

### Professional Communication

- **Follow up** - To check on the progress of something
- **Touch base** - To make contact briefly
- **Loop in** - To include someone in communication
- **Deep dive** - Detailed analysis or investigation

### Meeting Vocabulary

- **Agenda** - List of topics to be discussed
- **Action items** - Tasks assigned during a meeting
- **Stakeholder** - Person with interest in a project
- **Milestone** - Important point in project timeline

## Learning Methods

1. **Flashcards** - Digital or physical cards for memorization
2. **Context sentences** - Using new words in realistic sentences
3. **Technical reading** - Consuming content in English daily
4. **Practice conversations** - Using new vocabulary in discussions
