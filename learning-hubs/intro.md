# 📚 Learning Hubs

My study notes, one folder per area and one subfolder per course. The content comes from the [hubs](https://github.com/richardborgesdev/hubs) repository, which brings together the study hubs I kept in separate repositories until 2026.

Use the sidebar to browse the areas: AI, algorithms, software architecture, backend, cloud, web and mobile development, English and more. Each area opens with an index of its courses, and each course with its link, instructor and lessons.

Course code that is not part of the site (projects, exercises) is linked to GitHub.
